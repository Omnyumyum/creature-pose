work/venv/Scripts/python render_failures/report.py figs        # causes.json 의 figs → out/fig_{원인}.png (아이 그림 제외)

- 실패 형태마다 화면이 어떻게 다시 시도를 요청할지는 `retry-requirements.md`.
- 모아 보기 한 칸 = [원본 + 찾은 관절] [걷기 동작의 장들을 겹친 그림].
- 자동 표시(`report.flags`)는 후보일 뿐이고, 원인은 사람이 모아 보기를 보고 `causes.json` 에 적는다.
