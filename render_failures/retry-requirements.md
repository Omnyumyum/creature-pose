### 3-8. 실패 형태별 다시 시도 요청 (화면 요구사항 안)

3-7 에서 모은 실패는 대부분 「성공」으로 넘어가서, 지금 화면은 다시 해 보라고 말할 기회가 없다. 지금 있는 것은 오류 코드 세 가지(`NO_CHARACTER` · `MULTIPLE_CHARACTERS` · `LOW_CONFIDENCE`)의 「다시 찍기」와, 관절을 못 찾았을 때 관절 고치기로 보내는 것뿐이다. 그래서 실패 형태마다 화면이 무엇을 어떻게 다시 요청할지를 요구사항으로 적는다. 화면의 원본은 [05 화면설계서](05-screen-spec.md)이고, 이 표는 거기에 반영하기 전의 안이다.

**원칙**

1. 가장 가벼운 것부터 요청한다: 같은 사진으로 자동 재시도 → 같은 사진을 돌리기 · 형태 바꾸기 → 다시 찍기 → 어른에게.
2. 한 번에 바꿀 것을 하나만 말한다. 「밝은 곳에서 크게, 종이만 나오게」처럼 여러 개를 한꺼번에 말하지 않는다.
3. 아이 잘못으로 들리지 않게 한다(E-01 의 갸웃하는 표정, 「못했어요」가 아니라 「이렇게 해 볼까요」).
4. 움직일 수 있으면 거절하지 않는다. 일부만 못 찾았으면 찾은 만큼 움직이고, 고치기는 어른 화면의 선택으로 둔다.
5. 같은 까닭으로 두 번 이어 실패하면 세 번째에는 같은 말을 되풀이하지 않고 어른 도움을 권한다.

**실패 형태별 요청 방식**

| 실패 형태 | 화면이 알아내는 신호 | 어디서 | 아이에게 하는 말 (안) | 주된 버튼 → 하는 일 | 두 번째도 실패하면 |
|---|---|---|---|---|---|
| 빈 그림 (성공인데 결과가 비어 있음) | 새 오류 코드 `RENDER_EMPTY` **(서버 추가 필요)** | S-04 → E-01 | 친구가 안 보여요. 한 번 더 해 볼게요 | 묻지 않고 같은 사진으로 한 번 자동 재시도. 또 비면 「다시 찍기」 → S-03 | 어른 도움 권하기 |
| 다른 것이 함께 잡힘 (종이 가장자리 · 책상 · 옆 그림) | 잘라낸 그림이 사진 가장자리에 닿음 `cutout_warning: "edge"` **(서버 추가 필요)** | S-05 확인 | (잘라낸 그림을 보여 주며) 친구만 보이나요? | 「네」 → 그대로 진행. 「아니요」 → 「종이만 나오게 가까이서 찍어 볼까요?」 「다시 찍기」 → S-03 | 그리기 화면(S-03D) 권하기 |
| 연한 선 · 그림자로 몸이 조각남 | 잘라낸 그림이 상자에 비해 너무 작거나 조각이 여럿 `cutout_warning: "faint"` **(서버 추가 필요)** | S-05 확인 | 선이 잘 안 보여요. 진하게 따라 그려 볼까요? | 「다시 찍기」 → S-03 (안내는 「진하게」 하나만) | 「밝은 곳에서 찍어 볼까요?」로 말을 바꿈 |
| 누운(돌아간) 사진 | 지금은 신호 없음. 기본 뼈대 `joints_found=false` 이거나 `LOW_CONFIDENCE` 일 때 먼저 의심 | S-05 확인 · E-01 | 그림이 누워 있나요? 돌려 볼까요? | 「돌리기」 → 같은 사진을 90도 돌려 다시 분석 (다시 찍지 않음) | 「다시 찍기」 → S-03 |
| 고른 형태와 그림이 안 맞음 (두 발로 선 그림 · 앞모습 · 양쪽으로 펼친 날개) | `joints_found=false` + 고른 형태 (있음) | S-05 확인 | 다른 모습 친구일까요? | 「모습 다시 고르기」 → 같은 사진으로 형태만 바꿔 다시 분석 | 「몸 전체로 움직이기」(관절 없이 통째로) |
| 관절을 못 찾음 (위에 들지 않는 기본 뼈대) | `joints_found=false` (있음) | S-05 확인 | 친구 몸을 잘 못 찾았어요 | 아이: 「몸 전체로 움직이기」 · 「다시 찍기」. 어른: 관절 고치기(S-06) | 어른 도움 권하기 |
| 날개 등 일부를 못 찾음 | 못 찾은 부위 `parts_missing: ["wing"]` **(서버 추가 필요)** | 거절하지 않음 | (말하지 않음) | 몸을 통째로 움직이는 동작으로 재생. 어른 화면에 「날개 자리 고치기」 선택 | 해당 없음 |
| 시간 초과 · 서버 오류 | `ENGINE_TIMEOUT` 등 (있음) | E-01 | 조금 늦어지고 있어요. 다시 해 볼까요? | 「다시 하기」 → 같은 사진으로 다시 분석 (다시 찍지 않음) | 「처음으로」 |

**서버에 필요한 것**

- 렌더 결과가 비었는지 검사하고 `RENDER_EMPTY` 로 돌려주기.
- 분석 응답에 잘라내기 경고 `cutout_warning`(`edge` · `faint`)과 못 찾은 부위 `parts_missing` 넣기.
- 같은 사진으로 다시 분석할 때 돌린 각도와 바꾼 형태를 받기(돌리기 · 형태 바꾸기가 다시 찍기 없이 되도록).

**정할 것**

- 「몸 전체로 움직이기」를 아이 화면에 둘지, 자동으로 넘어갈지.
- 잘라내기 경고의 기준값. 3-7 의 124장으로 먼저 맞춰 본다.
- 누운 사진을 서버가 스스로 알아낼지, 지금처럼 묻는 것으로 둘지.
