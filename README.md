# creature-pose (비공개)

사람이 아닌 그림(네 발 동물부터)의 관절을 찾는 모델을 직접 학습해 보는 실험. 2026-11-17 시작.

## 왜

- 지금 서비스(drawtale-ai `runtime/ai_server/quadruped.py` 등)는 그림 모양에서 규칙으로 관절을 찾는다.
- 사람 그림은 Amateur Drawings 라는 정답 데이터가 있었지만, 동물 · 괴물 낙서에 관절을 표시한 공개 데이터는 없다.
- 그래서 「규칙이 찾은 관절을 정답 삼아 학습하면 규칙보다 나아지는가」를 네 발 하나로 먼저 확인한다.

## 순서

1. 형태별 시험 세트(정답 표시 있음)를 만든다. 아이 그림이 들어가므로 이 저장소에는 넣지 않는다(로컬에만).
2. Quick, Draw! 네 발 동물 낙서에 규칙을 돌려 자동 정답을 만들고, 얼마나 맞는지 잰다. **여기가 갈림길**: 정답 품질이 낮으면 학습하지 않는다.
3. 품질이 쓸 만하면 RTX 5080 PC 에서 네 발 모델을 학습해 1번 세트로 규칙과 비교한다.
4. 나아진 것이 확인되면 다른 형태(긴 몸 · 날개 · 지느러미 · 여러 다리)로 넓힌다.

## 규칙

- 학습에는 상업 이용이 되는 데이터만 쓴다(Quick, Draw! 는 CC BY 4.0). CC BY-NC 같은 비상업 데이터는 재기 · 확인용으로만.
- 받은 데이터 · 그린 그림 · 가중치는 커밋하지 않는다(`data/` · `out/` · `work/`).
- 아이가 그린 그림은 이 저장소와 클라우드 세션에 올리지 않는다.
- 글에는 긴 작대기(「—」「–」)를 쓰지 않는다.
